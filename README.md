# 🛡️ VPN Store — پلتفرم جامع فروش و مدیریت اشتراک VPN

**سامانه یکپارچه، امن و مدرن مدیریت اشتراک‌های VPN متصل به پنل 3X-UI و ربات تلگرام (Aiogram 3) با کنترل‌پنل تحت وب بهینه‌سازی‌شده برای گوشی‌های موبایل (Android Mobile-First).**

---

## 🌟 ویژگی‌های برجسته (Key Features)

- 📱 **مدیریت ۱۰۰٪ با گوشی اندروید:** بدون نیاز به ترمینال SSH، نانو (Nano) یا ویرایش دستی فایل‌های کانفیگ پس از نصب اولیه. تمامی تنظیمات مستقیماً از طریق مرورگر موبایل قابل تغییر است.
- ⚡ **نصب تک‌دستوری (One-Command Installer):** اسکریپت خودکار `setup.py` برای اوبونتو 24.04 LTS (ایجاد خودکار venv، وابستگی‌ها، دیتابیس، حساب ادمین، سرویس‌های systemd و فایروال).
- 🤖 **ربات تلگرام پیشرفته با Aiogram 3:** منوی ۸ گانه (خرید، تست رایگان، حساب کاربری، سرویس‌های من، کیف پول، پرداخت کارت‌به‌کارت، کد هدیه، پشتیبانی). ثبت‌نام خودکار کاربران جدید.
- 🔌 **یکپارچگی پایدار با پنل 3X-UI:** ساخت، تمدید، غیرفعال‌سازی، حذف و استعلام ترافیک کلاینت‌ها برای پروتکل‌های VLESS Reality، VMess، Trojan، VLESS WebSocket/gRPC.
- 🔗 **تولید خودکار لینک‌های اتصال واقعی:** تولید لینک‌های استاندارد و بدون باگ VLESS Reality با کلید عمومی (pbk) و shortId استخراج‌شده از اینباند واقعی سرور.
- 🔄 **همگام‌سازی خودکار ترافیک (Traffic Sync Worker):** جاب پس‌زمینه برای بررسی دوره‌ای ترافیک مصرفی و انقضای اکانت‌ها و قطع خودکار در 3X-UI در صورت اتمام حجم یا زمان.
- 💰 **سیستم مالی و کیف پول اتمیک:** مدیریت موجودی با تراکنش‌های پایگاه‌داده (Database Transactions) جهت جلوگیری از Race Condition، کسر همزمان و شارژ دوبل.
- 🛡️ **استرداد خودکار وجه (Auto-Refund):** در صورت بروز هرگونه قطعی یا خطای API در پنل 3X-UI هنگام ساخت کانفیگ، مبلغ بلافاصله به کیف پول کاربر بازگردانده می‌شود.
- 💳 **سیستم پرداخت دستی و کارت‌به‌کارت:** ارسال رسید، بررسی و تایید یا رد پرداخت‌ها در پنل ادمین با شارژ خودکار موجودی کاربر پس از تایید.
- 🎁 **سیستم کد هدیه و تست رایگان:** امکان تعریف کدهای تخفیف با سقف تعداد و تاریخ انقضا، و تست رایگان با محدودیت ۱ بار برای هر اکانت تلگرام.
- 🌐 **پشتیبانی دو زبانه (فارسی RTL و انگلیسی LTR):** طراحی تیره (Dark Mode) لوکس و بدون اسکرول افقی روی صفحات کوچک موبایل.

## 🚀 راهنمای نصب سریع روی اوبونتو 24.04 (Quick Installation)

### مرحله ۱: اتصال به سرور و اجرای نصب تک‌دستوری

روی سرور ابری اوبونتو ۲۴ خود، دستورات زیر را وارد کنید:

```bash
# کلون کردن پروژه از گیت‌هاب:
git clone https://github.com/6katalon-ux/phantomhub.git /opt/vpn_store
cd /opt/vpn_store

# اجرای نصاب خودکار:
sudo python3 setup.py
```

یا با استفاده از اسکریپت سریع Bash:

```bash
sudo bash install.sh
```

### عملیاتی که نصاب به صورت خودکار انجام می‌دهد:
1. بررسی نسخه پایتون (Python 3.12+) و سیستم‌عامل اوبونتو 24.04.
2. نصب پکیج‌های سیستمی مورد نیاز (`python3-venv`, `sqlite3`, `curl`, `ufw`, `nginx`).
3. ایجاد محیط مجازی پایتون (`.venv`) و نصب پکیج‌های `requirements.txt`.
4. ساخت کلیدهای رمزنگاری امن برای JWT و سشن‌ها.
5. ساخت دیتابیس SQLite با قابلیت WAL Mode و روابط Foreign Keys.
6. ایجاد حساب کاربری مدیر ارشد (Superadmin).
7. ایجاد ۳ سرویس سیستمی `systemd` (`vpnstore-web`, `vpnstore-bot`, `vpnstore-worker`).
8. فعال‌سازی استارت خودکار پس از ریبوت سرور (`systemctl enable`).
9. باز کردن پورت‌های لازم در فایروال UFW (پورت 8000، 80، 443، 22).
10. چاپ آدرس ورود به پنل و مشخصات ادمین در خروجی ترمینال.

## 📱 ورود به پنل مدیریت از طریق گوشی موبایل

پس از پایان نصب، مرورگر گوشی اندروید یا آیفون خود را باز کرده و آدرس زیر را وارد کنید:

```text
http://YOUR_SERVER_IP:8000
```

1. با نام کاربری و رمزعبور تولیدشده وارد شوید.
2. به تب **اتصال 3X-UI** بروید:
   - آدرس پنل (مثلاً `http://127.0.0.1:2053` یا پورت سفارشی)
   - نام کاربری و رمزعبور پنل سنایی/علیرضا
   - دکمه **تست اتصال** را بزنید تا وضعیت ارتباط سبز شود.
3. به تب **تنظیمات ربات تلگرام** بروید:
   - توکن دریافتی از @BotFather را جای‌گذاری کنید.
   - آیدی عددی ادمین و متن خوش‌آمدگویی را تنظیم کرده و ذخیره نمایید.
4. کار تمام است! ربات تلگرام به صورت زنده فعال شده و آماده ثبت‌نام و فروش اشتراک است.

## 📁 ساختار نرم‌افزاری پروژه (Architecture)

```text
vpn_store/
├── setup.py                    # نصاب خودکار تک‌دستوری

├── requirements.txt            # وابستگی‌های پایتون 3.12
├── README.md                   # مستندات کامل فارسی و انگلیسی
├── TROUBLESHOOTING.md          # راهنمای رفع خطاهای متداول
├── SECURITY.md                 # راهنمای امنیت سرور و پیکربندی SSL
│
├── app/
│   ├── main.py                 # برنامه FastAPI، روت‌ها و فایل‌های استاتیک
│   ├── core/
│   │   ├── config.py           # سیستم کانفیگ داینامیک در SQLite
│   │   ├── database.py         # ارتباط با پایگاه داده و حالت WAL
│   │   ├── security.py         # توکن‌های JWT و هش رمزعبور با bcrypt
│   │   └── logging.py          # لاگ‌های چرخشی و ابزار مشاهده لاگ
│   ├── models/
│   │   └── models.py           # مدل‌های دیتابیس (کاربران، پلن‌ها، سرویس‌ها...)
│   ├── services/
│   │   ├── xui_client.py       # کلاینت کامل REST API پنل 3X-UI
│   │   ├── vpn_provisioner.py  # مدیریت ساخت کانفیگ و بازگشت خودکار وجه
│   │   ├── wallet.py           # کیف پول اتمیک و جلوگیری از دابل‌شارژ
│   │   └── traffic_sync.py     # سینک دوره‌ای مصرف ترافیک
│   ├── bot/
│   │   ├── bot.py              # فایل اصلی رانر ربات تلگرام با Aiogram 3
│   │   ├── handlers.py         # هندلرهای پیام، خرید و پرداخت
│   │   └── keyboards.py        # کیبوردهای اینلاین و منوی اصلی
│   ├── workers/
│   │   └── scheduler.py        # کرون‌جاب‌های بکاپ دیتابیس و سینک ترافیک
│   └── web/
│       └── routes/
│           └── api.py          # اندپوینت‌های REST پنل مدیریت
│
├── systemd/                    # فایل‌های پیکربندی سرویس‌های لینوکس
├── nginx/                      # پیکربندی پروکسی معکوس وب‌سرور
├── data/                       # فایل vpn_store.db و secrets.json
├── backups/                    # پشتیبان‌های خودکار روزانه دیتابیس
└── logs/                       # لاگ‌های وب، ربات و پردازشگر
```

## 🛠️ دستورات مدیریتی سرویس‌ها (Systemd Commands)

| دستور | کاربرد |
| :--- | :--- |
| `sudo systemctl status vpnstore-web` | مشاهده وضعیت پنل اوب و API |
| `sudo systemctl status vpnstore-bot` | مشاهده وضعیت ربات تلگرام |
| `sudo systemctl status vpnstore-worker` | مشاهده وضعیت سینک ترافیک و بکاپ |
| `sudo systemctl restart vpnstore-web` | ریستارت پنل وب |
| `sudo systemctl restart vpnstore-bot` | ریستارت ربات تلگرام |
| `sudo journalctl -u vpnstore-bot -f` | مشاهده زنده لاگ‌های ربات تلگرام |

## 🔒 امنیت و اتصال دامنه با SSL رایگان (Let's Encrypt)

اگر مایلید به جای IP از دامنه استفاده کنید:

```bash
# ۱. قرار دادن دامنه در فایل nginx:
sudo cp /opt/vpn_store/nginx/vpnstore.conf /etc/nginx/sites-available/vpnstore.conf
sudo ln -s /etc/nginx/sites-available/vpnstore.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# ۲. فعال‌سازی خودکار HTTPS با سرتبوت:
sudo certbot --nginx -d your-domain.com
```
